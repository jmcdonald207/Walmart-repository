## Naming decisions
The existing `project1/` and `analysis/` notes are supporting materials; do not rename or delete original labs or change dated research retroactively. `README.md`, `walmart_all_models.py`, `models/*.py` and `references/*.py` have sensible executable names. `notesAboutProject.md` is nonstandard but not forbidden; keep rather than delete without reviewing its provenance.

A clean GitHub Actions run is not a completed source-reconciled valuation. Before submitting, fix historical dates/units and bridge conventions, calculate verified P/E and EV/EBITDA, provide a justified valuation range, fill human records, generate PDFs, record videos and correct transcripts. Never submit placeholder records as complete.
